# Teng Zihan — Personal Homepage

A polished one-page academic / AI systems portfolio designed for GitHub Pages.

## Deploy on GitHub Pages

1. Create a repository named `<your-github-username>.github.io`.
2. Copy `index.html` and `cv.pdf` into the repository root.
3. Commit and push to the `main` branch.
4. Open `https://<your-github-username>.github.io`.

## Before publishing

Edit the bottom Contact section in `index.html` and replace the `#` placeholders with your:
- GitHub URL
- Google Scholar URL
- LinkedIn URL

Optional:
- Replace the TZ monogram avatar with your own photo.
- Add Paper / Code / OpenReview links in the Publications section.
- Remove any internship metrics you do not want to expose publicly.

Everything else is self-contained: no build system, package manager, or external assets are required.
