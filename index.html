EMNLP 2026 · Main

SlimKV

Joint Token-Feature KV Cache Compression with Reconstruction-Free Beacon Attention. SlimKV compresses the cache in both token and feature dimensions, then performs attention directly in the compressed latent space without reconstructing full-dimensional Keys.

01Jointly compresses beacon tokens and their KV features with adaptive low-rank budgets across layers.
02Exploits asymmetric RoPE dependence to enable reconstruction-free latent-space attention.
03Targets long-context inference where memory pressure and reconstruction overhead become dominant.
32×KV cache compression
7.34×attention speedup @ 128K
3.38×end-to-end decode speedup

KV Cache Compression & Inference Acceleration

A hidden-state low-rank compression pipeline using cross-layer SVD, with offline basis precomputation to reduce prefill overhead while preserving long-context quality.
